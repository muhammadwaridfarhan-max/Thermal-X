# Thermal-X

**Root Module + App** untuk ON/OFF Thermal Throttling & Fast Charging

## Fitur
- Toggle ON/OFF di aplikasi
- Support Magisk + KernelSU
- Auto detect thermal & fastcharge
- Bisa di-override kapan saja

## Install
1. Install module di Magisk / KernelSU
2. Install app
3. Buka app → pilih module (Magisk/KernelSU) → toggle
